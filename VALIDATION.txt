THE FOUR REPORTED GAPS (reproduced first)
A new test fed the four states a 3.0.0 agent would record into the readiness
check. Before the fix it failed: 3.0.0 returned Development-Ready with no issues
for all four. After the fix none of them is Development-Ready. The same four gaps
in the 3.1.0 format, each as the only defect, give: 1 Ready for Review (approvals
stale, "changed BR-1"), 2 Ready for Review (rule and criterion text missing from the
document), 3 Needs Evidence (BR-1/dab not assessed), 4 Needs Evidence (BR-1/EV-404
unknown).

  a revision is recorded, not that it is current.

TEAM-MACHINE SMOKE TEST
1. Install into a throwaway copy with the form and, separately, with
   Install-PBIBuilder.cmd; run Check installed files / -Action Verify.
2. Reopen the IDE; confirm one agent "Akzo SDD PBI Builder - <project>" appears.
3. Run the setup-check prompt; confirm real source access.
4. Refine one PBI to Ready for Review; run Check PBI readiness, give the agent the
   approval basis, record approvals, and confirm the check reports Development-Ready.
   Change one rule afterwards and confirm the approvals turn stale.
5. Open one existing 3.0.0 PBI with the agent and confirm the migration keeps the
   old file in history/ and the old approvals in approvalHistory.
